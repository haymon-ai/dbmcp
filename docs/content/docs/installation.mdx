Database MCP is distributed as a single binary with no runtime dependencies. Choose the installation method that works best for your setup.

## Quick Install (recommended)

**macOS, Linux, WSL**:

```bash
curl -fsSL https://dbmcp.haymon.ai/install.sh | bash
```

Or with `wget`:

```bash
wget -qO- https://dbmcp.haymon.ai/install.sh | bash
```

**Windows** (PowerShell):

```powershell
irm https://dbmcp.haymon.ai/install.ps1 | iex
```

**Windows** (CMD):

```batch
curl -fsSL https://dbmcp.haymon.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

This detects your platform, downloads the correct binary, and installs it. Re-run the same command to upgrade to the latest version.

To install to a custom directory:

```bash
INSTALL_DIR=/opt/bin curl -fsSL https://dbmcp.haymon.ai/install.sh | bash
```

```powershell
$env:INSTALL_DIR = "C:\tools\dbmcp"; irm https://dbmcp.haymon.ai/install.ps1 | iex
```

```batch
set INSTALL_DIR=C:\tools\dbmcp && curl -fsSL https://dbmcp.haymon.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

## Prebuilt Binaries

Download the latest release from GitHub.

### Linux

**x86_64 (Intel/AMD)**:

```bash
curl -LO https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-x86_64-unknown-linux-gnu.tar.gz
tar xzf dbmcp-x86_64-unknown-linux-gnu.tar.gz
sudo mv dbmcp /usr/local/bin/
```

**aarch64 (ARM)**:

```bash
curl -LO https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-aarch64-unknown-linux-gnu.tar.gz
tar xzf dbmcp-aarch64-unknown-linux-gnu.tar.gz
sudo mv dbmcp /usr/local/bin/
```

### macOS

**Apple Silicon (M1/M2/M3/M4)**:

```bash
curl -LO https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-aarch64-apple-darwin.tar.gz
tar xzf dbmcp-aarch64-apple-darwin.tar.gz
sudo mv dbmcp /usr/local/bin/
```

**Intel**: not supported since 0.16.0. ONNX Runtime, used for NER-based PII detection, ships no x86_64 macOS build. Use the [Docker](#docker) image instead.

### Windows

**x86_64**:

Download the latest release:

```powershell
Invoke-WebRequest -Uri https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-x86_64-pc-windows-msvc.zip -OutFile dbmcp.zip
Expand-Archive dbmcp.zip -DestinationPath .
```

Move `dbmcp.exe` to a directory on your PATH, or run it directly from the extracted location.

Verify the installation:

```powershell
dbmcp.exe --help
```

---

For older versions or other assets, see the [GitHub Releases](https://github.com/haymon-ai/dbmcp/releases) page.

Verify the installation (Linux/macOS):

```bash
dbmcp --help
```

## Docker

No Rust toolchain or compilation needed.

```bash
docker pull ghcr.io/haymon-ai/dbmcp:latest
```

**stdio mode** (for Claude Desktop, Cursor, and other MCP clients):

```bash
docker run -i --rm \
  -e DBMCP_DB_BACKEND=postgres \
  -e DBMCP_DB_HOST=host.docker.internal \
  -e DBMCP_DB_USER=postgres \
  # -e DBMCP_PII_ENABLE=true \
  # -e DBMCP_PII_OPERATOR=replace \
  # -e DBMCP_PII_CATEGORIES=financial,government \
  ghcr.io/haymon-ai/dbmcp
```

**HTTP mode** (for web clients and remote access):

```bash
docker run --rm \
  -e DBMCP_DB_BACKEND=postgres \
  -e DBMCP_DB_HOST=host.docker.internal \
  -e DBMCP_DB_USER=postgres \
  # -e DBMCP_PII_ENABLE=true \
  # -e DBMCP_PII_OPERATOR=replace \
  # -e DBMCP_PII_CATEGORIES=financial,government \
  -e DBMCP_TRANSPORT=http \
  -e DBMCP_HTTP_HOST=0.0.0.0 \
  -e DBMCP_HTTP_AUTH_TOKEN=change-me \
  -p 9001:9001 \
  ghcr.io/haymon-ai/dbmcp
```

Binding `0.0.0.0` requires `DBMCP_HTTP_AUTH_TOKEN`; clients must send `Authorization: Bearer <token>`. Use a long random value (e.g. `openssl rand -hex 32`). The image has no shell or `curl`, so check health from the orchestrator with HTTP probes against [`/healthz` and `/readyz`](/docs/configuration#health-probes) rather than a Docker `HEALTHCHECK`.

**SQLite with a mounted volume**:

```bash
docker run -i --rm \
  -e DBMCP_DB_BACKEND=sqlite \
  -e DBMCP_DB_NAME=/data/my.db \
  # -e DBMCP_PII_ENABLE=true \
  # -e DBMCP_PII_OPERATOR=replace \
  # -e DBMCP_PII_CATEGORIES=financial,government \
  -v /path/to/local/db:/data \
  ghcr.io/haymon-ai/dbmcp
```

Images are available for `linux/amd64` and `linux/arm64`. A specific version can be pinned with `ghcr.io/haymon-ai/dbmcp:<version>`.

To run the image on Kubernetes, use the [Helm chart](/docs/kubernetes).

## Verify Downloads

Releases after 0.17.0 publish a SHA-256 checksum for every release asset, signed build provenance attestations for the binaries, the Docker image, and the [Helm chart](/docs/kubernetes), and a keyless [cosign](https://docs.sigstore.dev/cosign/) signature for the image and the chart.

### Checksums

Each archive has a matching `.sha256` file:

```bash
curl -LO https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-x86_64-unknown-linux-gnu.tar.gz
curl -LO https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-x86_64-unknown-linux-gnu.tar.gz.sha256
sha256sum -c dbmcp-x86_64-unknown-linux-gnu.tar.gz.sha256
```

On macOS, use `shasum -a 256 -c` instead of `sha256sum -c`. On Windows (PowerShell), download the checksum next to the `dbmcp.zip` from the [Windows](#windows) steps and compare:

```powershell
Invoke-WebRequest -Uri https://github.com/haymon-ai/dbmcp/releases/latest/download/dbmcp-x86_64-pc-windows-msvc.zip.sha256 -OutFile dbmcp.zip.sha256
$expected = (Get-Content dbmcp.zip.sha256).Split(' ')[0]
(Get-FileHash dbmcp.zip -Algorithm SHA256).Hash -eq $expected
```

This prints `True` when the hashes match. PowerShell's `-eq` ignores case, so the uppercase hash from `Get-FileHash` matches the lowercase one in the file.

### Build Provenance

Attestations prove an asset was built by this repository's release workflow. Verify them with the [GitHub CLI](https://cli.github.com/):

```bash
gh attestation verify dbmcp-x86_64-unknown-linux-gnu.tar.gz --repo haymon-ai/dbmcp
gh attestation verify oci://ghcr.io/haymon-ai/dbmcp:<version> --repo haymon-ai/dbmcp
gh attestation verify oci://ghcr.io/haymon-ai/charts/dbmcp:<version> --repo haymon-ai/dbmcp
```

### Image Signature

```bash
cosign verify ghcr.io/haymon-ai/dbmcp:<version> \
  --certificate-identity-regexp '^https://github.com/haymon-ai/dbmcp/\.github/workflows/release\.yml@refs/tags/v' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

To verify the Helm chart, use `ghcr.io/haymon-ai/charts/dbmcp:<version>` in the same command.

## Package Managers

### Cargo

If you have the [Rust toolchain](https://rustup.rs/) installed:

```bash
cargo install dbmcp
```

This builds from source and installs the binary to `~/.cargo/bin/`.

Verify the installation:

```bash
dbmcp --help
```

### npm

With [Node.js](https://nodejs.org/) 18 or newer, MCP clients can launch dbmcp through `npx` without a separate install step:

```json
{
  "mcpServers": {
    "dbmcp": {
      "command": "npx",
      "args": ["-y", "@haymon-ai/dbmcp"],
      "env": {
        "DBMCP_DB_BACKEND": "mysql",
        "DBMCP_DB_USER": "root"
      }
    }
  }
}
```

Pin a version with `@haymon-ai/dbmcp@<version>`. To install globally instead:

```bash
npm install -g @haymon-ai/dbmcp
```

The package is a small launcher. npm installs the native binary for your platform as an optional dependency, so don't install with `--omit=optional`. Prebuilt packages exist for Linux x64 and arm64 (glibc 2.34 and libstdc++ from GCC 12 or newer; musl/Alpine is not supported), macOS arm64, and Windows x64.

## Build from Source

### Prerequisites

- [Git](https://git-scm.com/)
- [Rust toolchain](https://rustup.rs/) (edition 2024, requires Rust 1.85+)

### Build

```bash
git clone https://github.com/haymon-ai/dbmcp.git
cd dbmcp
cargo build --release
```

Copy the binary to a directory on your PATH:

```bash
sudo cp target/release/dbmcp /usr/local/bin/
```

Verify the installation:

```bash
dbmcp --help
```

## Comparison

| Method | Ease of Install | Auto Updates | Version Flexibility | Prerequisites | Platform Coverage |
|--------|----------------|--------------|--------------------|--------------|--------------------|
| Quick Install | Single command | Re-run to upgrade | Latest release | curl/wget or PowerShell | macOS, Linux, WSL, Windows |
| Docker | `docker pull` | Pull latest tag | Any release tag | Docker | Linux, macOS, Windows |
| Prebuilt Binary | Simple download | None | Any release | None | Linux, macOS, Windows |
| npm / npx | No install step with `npx` | Unpinned `npx` fetches the latest | Any published version | Node.js 18+ | Linux (glibc), macOS arm64, Windows x64 |
| Cargo Install | One command | `cargo install` to update | Any published version | Rust toolchain | All platforms Rust supports |
| Build from Source | Multiple steps | Manual (git pull + rebuild) | Any commit/branch | Git + Rust toolchain | All platforms Rust supports |
